Delta AH500 → Modbus address map

            
Source: Delta AH500 Operation Manual, Appendix B.1 "Device Addresses".
              Hex = zero-based protocol address on the wire. Reference = one-based 6-digit address (table digit + address + 1).
              The PLC device number is not the Modbus address for X, Y, SM, SR, S, T, C, HC, E.

X/Y bit address = base + word×16 + bit (X1.0 = 6010h). A bit inside a word (D15000.3) is read as holding register D15000 and bit 3 is extracted.
