Delta AH500 → Modbus address map

            
Source: Delta AH500 Operation Manual, Appendix B.1 "Device Addresses".
              Hex = zero-based protocol address on the wire. Reference = one-based 6-digit address (table digit + address + 1).
              The PLC device number is not the Modbus address for X, Y, SM, SR, S, T, C, HC, E.

X/Y bit address = base + word×16 + bit (X1.0 = 6010h). A bit inside a word (D15000.3) is read as holding register D15000 and bit 3 is extracted.

Equipment (status derived from tags)

          

            

        

        
Motor: TRIPPED if the trip input is ON → RUNNING if the run feedback or the start command (DO) is ON → otherwise STOPPED.
          Valve: OPEN if the open limit switch is ON, otherwise CLOSED. Run hours count while RUNNING; Starts count each change to RUNNING.

Plant Assistant (AI)

          
With an Anthropic API key the assistant answers any question in full, from the live plant data
            and the plant knowledge (P&ID, control rules, alarms). Without a key it runs in basic mode (fixed answers from the live data).
            The key is stored only on this server (backend/data/ai_config.json) and is never sent back to any browser.

WhatsApp alarm alerts

          
When an alarm becomes active (and when it clears) the dashboard sends a WhatsApp message to the numbers below,
            through the official Meta WhatsApp Cloud API. The access token stays on this server and is never shown again.

Setup (one time, in Meta)

          
    
            
  1. At developers.facebook.com create an app → add WhatsApp, and link the company's Meta Business account and a phone number for the plant.
    2. 
            
  2. Copy the Phone number ID (not the phone number) and create a permanent access token (System user → token with whatsapp_business_messaging).
    3. 
            
  3. In WhatsApp Manager → Message templates, create a Utility template named plant_alarm, language English, body:
    
              ⚠ {{1}}
Alarm {{2}}: {{3}}
Time: {{4}}
              Wait until Meta shows it as Approved.
    4. 
            
  4. Fill in the fields here, tick Send WhatsApp alerts, Save, then Send test message.
    5. 
            
  5. While the Meta app is in test mode, only numbers added to its test list receive messages.
    6. 
          

          
Variables: {{1}} site name · {{2}} ACTIVE / CLEARED · {{3}} alarm text · {{4}} time (IST and UTC). This PC needs internet access to graph.facebook.com. Every message is recorded in the Activity log.
